# AI Spend Audit

AI Spend Audit is a SaaS-style web application that helps startups analyze and optimize AI tooling costs across platforms like ChatGPT, Claude, Cursor, and GitHub Copilot.

## Features

- Audit form
- Rule-based recommendations
- Savings calculations
- Supabase backend
- Persistent form state
- Responsive UI

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase

## Deployment

Deployed on Vercel.
